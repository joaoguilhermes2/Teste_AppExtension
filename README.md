# Teste_AppExtension

Extensão simples do Google Chrome com popup para testar entrada de nome.

## Como carregar no Chrome

1. Abra o Chrome e acesse `chrome://extensions/`.
2. Ative o **Modo do desenvolvedor**.
3. Clique em **Carregar sem compactação**.
4. Selecione esta pasta (`Teste_AppExtension`).
5. Clique no ícone da extensão **App de Teste** para abrir o popup.

## Estrutura

- `manifest.json`: configuração da extensão (Manifest V3).
- `popup.html`: interface do popup.
- `popup.css`: estilos do popup.
- `popup.js`: lógica do botão e mensagem de sucesso.
